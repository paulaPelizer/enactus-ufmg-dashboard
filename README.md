# Enactus UFMG — Radar de Oportunidades

Dashboard web independente para monitoramento de editais, modelos jurídicos e oportunidades da Enactus UFMG.

A aplicação é publicada via GitHub Pages e possui:
- autenticação local com dados criptografados;
- dashboard derivado do mapeamento em Excel;
- filtros por coluna e busca global;
- Radar automático de oportunidades via GitHub Actions;
- espaços reservados para as identidades visuais oficiais.

> O painel não depende do ChatGPT para ser acessado.
